## ⚡ 快速入门

1. 安装 Nexora
    ```bash
    npm install -g Nexora
    ```
2. 启动 Nexora

    ```bash
    npx Nexora start
    ```

3. 打开 [http://localhost:3000](http://localhost:3000)

## 🌱 环境变量

Nexora 支持不同的环境变量来配置您的实例。您可以在 `packages/server` 文件夹中的 `.env` 文件中指定变量。请参阅 `packages/server/.env.example` 了解可用选项。
